# عاداتي: طريقة النشر على GitHub Pages

1. اعمل حساب مجاني على github.com.
2. اضغط New repository، اكتب اسم مثل habits، واختار Public، ثم Create repository.
3. اضغط Add file ثم Upload files، وارفع كل الملفات اللي جوه الفولدر ده (index.html و manifest.webmanifest و sw.js والصور الثلاثة). ارفعها نفسها، مش ملف الـ zip.
4. اضغط Commit changes.
5. من Settings ثم Pages: في Source اختار Deploy from a branch، وفي Branch اختار main و / (root)، ثم Save.
6. استنى دقيقة أو اتنين. الرابط هيبقى: https://اسمك.github.io/habits/
7. افتح الرابط من Safari على الايفون، اضغط زر المشاركة، ثم Add to Home Screen.

ملاحظات:
- بياناتك على الرابط الجديد منفصلة عن النسخة اللي في Claude. انقلها من شاشة الإحصائيات: انسخ من النسخة القديمة، والصق واضغط استرجع في الجديدة.
- لتحديث التطبيق: ارفع index.html الجديد فوق القديم في نفس المستودع.
